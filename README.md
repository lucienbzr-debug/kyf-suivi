# Kilimo ya Furaha · Suivi

Application hors-ligne (PWA) de profilage des ménages et de suivi des distributions
(kits de semences et petit bétail) du projet KILIMO YA FURAHA — Enabel · Rikolto, Nord-Kivu.

Ce dépôt ne contient **aucune donnée personnelle** : le registre des bénéficiaires est transmis aux
téléphones par un paquet de configuration chiffré, préparé par le superviseur.

Utilisation : ouvrir https://lucienbzr-debug.github.io/kyf-suivi/ dans Chrome sur Android, puis
« Ajouter à l'écran d'accueil ». L'application fonctionne ensuite sans connexion.
